# Project Agent Instructions

## Git restrictions

Do not run `git add`, `git commit`, `git push`, `git pull`, `git merge`, `git rebase`, or otherwise modify the Git repository history or remote repository.

Do not run `git diff --check`.

You may inspect Git status and diffs when necessary.

After completing code changes, stop and provide a concise summary of the files changed. The user will handle `git add`, `git commit`, and `git push` manually.
